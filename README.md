# Zeitgeist Portfolio

A modern, responsive personal portfolio website built with HTML5, CSS3, and JavaScript.



## Customization

### Update Personal Information

1. **Name/Title**: Edit the `nav-brand` and `hero-title` in `index.html`
2. **About Text**: Update the paragraph content in the About section
3. **Contact Links**: Replace placeholder URLs in the Contact section
4. **Email**: Update `your-email@example.com` with your actual email

### Add Your CV

To add your CV, you can:
- Embed a PDF viewer
- Add a downloadable PDF link
- Display education and work experience in a formatted section
- Link to an external CV platform

Replace the `cv-placeholder` div in `index.html` with your CV content.
